# ChronicleCompanionTBC

> _Every raid tells a story. Chronicle helps you read it._

The official companion addon for **[ChronicleClassic.com](https://chronicleclassic.com/?utm_source=github&utm_medium=referral&utm_campaign=readme&utm_id=chronicle_companion_tbc&utm_content=intro)** — created and maintained by the Chronicle team. ChronicleCompanionTBC leverages the existing TBC combat log to enrich uploads with extended metadata so Chronicle can transform them into clear, actionable insights for raid leaders.

⚙️ **Built for WoW 2.4.3 clients** (The Burning Crusade)

Upload your logs at **[chronicleclassic.com](https://chronicleclassic.com/?utm_source=github&utm_medium=referral&utm_campaign=readme&utm_id=chronicle_companion_tbc&utm_content=upload_intro)**.

## Installation

1. Download the latest release
2. Extract to your `Interface/AddOns/` folder
3. Ensure the folder is named `ChronicleCompanionTBC`
4. Restart WoW
